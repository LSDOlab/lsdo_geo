# Advanced Examples

The `examples/advanced_examples` directory contains complex multidisciplinary examples:

* **Lift + Cruise eVTOL (`lift_plus_cruise/`)**:
  - `ex_lift_plus_cruise_with_inequalities.py`: Full eVTOL configuration parameterization with geometric inequality constraints.
  - `ex_lift_plus_cruise_timings.py`: Performance benchmarking and solver timings for complex geometric formulations.
